## Default Permission

Allows the media-session commands Pulse's player uses to control the native Android ExoPlayer (queue, transport, volume/speed, state).

#### This default permission set includes the following:

- `allow-set-queue`
- `allow-play`
- `allow-pause`
- `allow-next`
- `allow-previous`
- `allow-seek-to`
- `allow-seek-by`
- `allow-set-volume`
- `allow-set-speed`
- `allow-set-stop-at-track-end`
- `allow-stop-playback`
- `allow-get-state`
